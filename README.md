# Daylight

Current version: **v0.0.6**

A calm, mobile-first task randomizer that starts with three tasks and lets the user add more randomized tasks one at a time. Added tasks can be swiped left and removed while the original three remain the daily minimum. It includes 150 rotating inspirational messages, individual task rerolls, dynamic completion counts, an in-app changelog, a completed-task calendar, on-device persistence, offline support, and installable app metadata for iPhone and Android.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and folder in this project to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published URL on your phone.

## Install as an app

- **iPhone/iPad:** Publish the complete project first, then open its HTTPS site in Safari, tap **Share**, and choose **Add to Home Screen**. Opening a downloaded `index.html` file directly is not a reliable way to install a custom Home Screen icon.
- **Android:** Open the site in Chrome, open the browser menu, then tap **Install app** or **Add to Home screen**.

If an older grey “D” shortcut is already on the iPhone Home Screen, delete that shortcut, deploy this updated folder including every file inside `icons`, refresh the published site in Safari, and add it to the Home Screen again. iOS caches Home Screen artwork aggressively.

All tasks, daily progress, and completion history are stored locally on the current device. No account or server is needed.
